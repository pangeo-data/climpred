# Contributing to climpred

The full guide is in our documentation: <https://climpred.readthedocs.io/en/latest/contributing.html>.

Short version, for humans and AI coding agents alike
(see [AI-assisted contributions](https://climpred.readthedocs.io/en/latest/contributing.html#ai-contributions)
and [discussion #972](https://github.com/pangeo-data/climpred/discussions/972)):

1. **Issue first, PR later.** Explain why something is a problem for how you use climpred. Open a PR once a maintainer agrees.
2. **Bring a use case.** "An AI found a bug" is not a use case.
3. **Prefer simplifications:** fewer lines, more readable, more xarray, less numpy.
4. **Be the first human reviewer.** Only submit code you understand. Start the PR with a short gist that you wrote yourself, and share your (initial) prompt.
5. **Keep the volume reviewable**, and **run tests locally** before using CI minutes.

PRs that skip these steps may be closed without detailed review.

Please also follow our [Code of Conduct](CODE_OF_CONDUCT.md).
